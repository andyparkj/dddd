# Autopilot Plan (스스로 질문하고 반복한 실행 기록)

## 라운드 1: 무엇이 부족했는가?
- Q: 왜 사용자가 불만족했는가?
- A: 정적 프로토타입만 있었고, 백엔드/운영 기능/실전 흐름이 없었음.

## 라운드 2: 무엇을 자동으로 보완할 것인가?
- Q: 비전공자에게 필요한 최소 실전 기능은?
- A: 실행 1줄, 문의 저장, 관리자 조회, 에러 메시지, 보안 기본선.

## 라운드 3: 구현 우선순위
1. 서버 + API
2. 프론트 폼 연동
3. 애니메이션 보강
4. 운영 문서화

## 라운드 4: 검증 루프
- 서버 실행 확인
- health API 확인
- 문의 생성 확인
- 관리자 조회 확인

## 다음 반복 개선 예정
- SQLite/PostgreSQL로 데이터 영속성 강화
- 관리자 대시보드 UI 추가
- 이메일 알림(SMTP/Resend) 연동
- reCAPTCHA 도입
