# Flux - SaaS Landing Page Template

A modern, Framer-style SaaS landing page template built with pure HTML, CSS, and JavaScript.

## Features

- Dark theme with gradient accents
- Scroll-triggered animations (Intersection Observer)
- Responsive design (mobile, tablet, desktop)
- Interactive pricing toggle (monthly/yearly)
- Smooth scroll navigation
- Dashboard mockup in hero section
- Clean, modular code structure

## Sections

- Navigation (fixed, blur on scroll)
- Hero (badge, headline, CTA, dashboard preview, trusted logos)
- Features (6 feature cards with icons)
- How It Works (3 steps with visuals)
- Pricing (3 tiers with toggle)
- Testimonials (3 cards)
- CTA
- Footer

## Usage

Open `index.html` in a browser. No build tools required.
