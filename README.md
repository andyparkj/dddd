# WEBDOT 클론 프로젝트 (비개발자용 진행 가이드)

아래 순서대로만 진행하면, 코딩을 몰라도 **원본 사이트와 최대한 동일한 결과물**을 만들 수 있도록 정리했습니다.

## 1) 이 프로젝트의 현재 상태
- `index.html`: 페이지 구조(섹션/문구/폼)
- `styles.css`: 디자인(색/간격/반응형/카드)
- `script.js`: 히어로 슬라이드 자동 전환

> 중요: “완벽히 동일”을 위해서는 실제 원본의 이미지/영상/아이콘/폰트/애니메이션 스펙/문구가 모두 필요합니다.

---

## 2) 비개발자도 가능한 실행 방법
### 방법 A. 가장 쉬운 방법 (VS Code + Live Server)
1. VS Code 설치
2. 이 폴더 열기
3. `index.html` 우클릭 → **Open with Live Server**
4. 브라우저에서 결과 확인

### 방법 B. 터미널 한 줄
```bash
python3 -m http.server 5500
```
브라우저에서 `http://localhost:5500` 접속

---

## 3) “완벽 복제”를 위한 필수 체크리스트
아래 자료가 있어야 동일도를 끌어올릴 수 있습니다.

- [ ] 데스크톱 캡처 (1920px)
- [ ] 태블릿 캡처 (768px)
- [ ] 모바일 캡처 (390px)
- [ ] 스크롤 전 구간 캡처
- [ ] 사용 이미지 원본 파일
- [ ] 로고 SVG/PNG 원본
- [ ] 사용 폰트 정보(이름/굵기)
- [ ] 버튼/호버/애니메이션 영상 캡처
- [ ] 폼 전송 후 동작(감사 페이지/알림)
- [ ] 푸터 사업자 정보 최종본

## 4) 작업자가 반드시 먼저 받아야 하는 질문지
아래 질문은 `QUESTIONNAIRE.md`에 정리되어 있습니다.

1. 이번 1차 목표가 “픽셀 단위 100% 동일”인가요, 아니면 “95% 시각 동일 + 텍스트 수정 가능”인가요?
2. 원본의 이미지/아이콘/영상을 그대로 써도 되나요? (저작권/라이선스 확인)
3. 모바일 기준 해상도(예: 390x844)와 우선 브라우저(Chrome/Safari)는 무엇인가요?
4. 폼 제출 시 어디로 저장해야 하나요? (이메일/구글시트/CRM)
5. 애니메이션 속도(초), 진입 효과(페이드/슬라이드), 스크롤 효과를 동일 적용할까요?
6. 텍스트/회사 정보/전화번호/사업자번호 최종본은 확정됐나요?
7. SEO 메타 태그(제목/설명/OG 이미지)도 동일하게 맞출까요?
8. 배포 위치는 어디인가요? (카페24/가비아/Vercel/Netlify)

---

## 5) 파일 수정 포인트 (비개발자 기준)
- 문구 수정: `index.html`
- 색상/간격 수정: `styles.css`
- 슬라이드 속도 수정: `script.js`의 `3500` 값을 변경
